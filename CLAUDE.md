# Claude Code contributor guide

@AGENTS.md

This repository develops the Voiceflow agent plugin; reading its customer setup
guide is not an instruction to install it, sign in, or modify a customer's account.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for the repository map and checks,
[SECURITY.md](SECURITY.md) for private reporting, and
[docs/security-checks.md](docs/security-checks.md) for secret scanning.
Keep shared contributor rules in AGENTS.md so Claude and other agents follow
the same requirements. Keep personal instructions and credentials out of commits.
