# Voiceflow Agent Plugins

Skills and setup guides for using Voiceflow with coding agents.

## Goal

A customer pastes one setup prompt. Their coding agent installs or connects the required tools, verifies authentication and skill availability, then asks:

> You're connected to Voiceflow. What would you like to build or improve?

Project selection and building begin after the customer answers.

## Direction

- Shared skills and setup instructions for Claude Code, Cursor, and Codex.
- Use the existing official Voiceflow CLI and supported browser authentication.
- Use the [Voiceflow website docs](https://www.voiceflow.com/docs) as the source of truth for product knowledge.
- Maintain the setup guide in this repository; the website will publish a versioned Markdown copy.
- Keep installation repeatable and verify skills work in both the current conversation and future conversations.

## Status

Initial repository. Setup instructions, skill packages, and compatibility testing are still to be implemented.
